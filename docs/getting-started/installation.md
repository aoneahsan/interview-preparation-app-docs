# Installation & access

**PrepAI runs in any modern browser with nothing to install, and can optionally be added to your home screen as a Progressive Web App (PWA) or installed as a native Android app.** There is no paid download — the free tier is available the moment you sign in.

## 1. Use it in a browser (fastest)

Open **[interviewpai.aoneahsan.com](https://interviewpai.aoneahsan.com)** in Chrome, Edge, Firefox, Safari, or any current browser. The full app — practice drills, mock interviews, peer reviews, dashboard, and tools — works directly in the tab. The 50+ developer tools are usable without even signing in; signing in unlocks progress tracking, mock interviews, and reviews.

**Recommended browsers:** the latest version of Chrome, Edge, Firefox, or Safari on desktop, or Chrome/Safari on mobile. PrepAI is responsive from 320px phones up to wide desktops.

## 2. Install it as a Progressive Web App

Installing the PWA gives you an app icon, a standalone window (no browser chrome), and offline access to already-loaded content.

- **Desktop Chrome/Edge:** click the install icon in the address bar, or open the browser menu and choose **Install PrepAI**.
- **Android Chrome:** open the menu (⋮) and tap **Add to Home screen** / **Install app**.
- **iOS Safari:** tap the **Share** button, then **Add to Home Screen**.

See the dedicated guide: **[Install PrepAI as a PWA](../guides/install-as-pwa.md)**.

## 3. Get the Android app

The native Android build is available on Google Play:

> **[Get PrepAI on Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.interviewpai)** — package id `com.aoneahsan.interviewpai`.

The Android app is built with Capacitor and wraps the same web experience with native niceties (splash screen, status-bar theming, haptics, native share sheet, and in-app review prompts).

## 4. iOS

PrepAI is built cross-platform with Capacitor, so an iOS build is technically supported. As of this writing the iOS app is not yet published to the App Store — iPhone and iPad users should use the **web app** or **add it to the Home Screen** from Safari (step 2 above), which gives a near-native experience.

## System requirements

| Requirement | Detail |
|---|---|
| Browser | Any current evergreen browser (Chromium, Firefox, Safari). |
| Account | A Google account (sign-in is Google-only — see [Accounts & sign-in](./account-and-sign-in.md)). |
| Network | Needed for sign-in, syncing progress, mock interviews, and reviews. Already-loaded tools and drills keep working offline. |
| Cost | $0 for the free tier. Optional paid plans add convenience features — see [Subscription plans](../concepts/subscription-plans.md). |
