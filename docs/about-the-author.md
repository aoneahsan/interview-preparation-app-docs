## About PrepAI

PrepAI grew out of a simple conviction: preparing for a technical interview shouldn't require a subscription. By running code in the browser, leaning on free service tiers, and processing files on-device, PrepAI delivers a full prep workflow — drills, mock interviews, peer reviews, analytics, and tools — at no cost to its users.

It's part of a wider portfolio of products built on the same principles: client-first, privacy-respecting, and free where it can be. You can find more of that work via the links above.
